# bimmer-kurd 🚗

**یەکەم کۆمیونیتی کوردی بۆ کۆدینگ و چاککردنی ئۆتۆمبێلەکانی BMW**
*The first Kurdish community for BMW coding, diagnostics & DIY.*

> ⚠️ ئەم پرۆژەیە سەربەخۆیە و هیچ پەیوەندییەکی بە کۆمپانیای BMW AG ـەوە نییە.
> This is an independent community project, not affiliated with BMW AG.

## ناوەڕۆک
| بەش | وەسف |
|---|---|
| [docs/models](docs/models) | زانیاری بەپێی شاسی (E90, F30, G20, F10, ...) |
| [docs/coding](docs/coding) | کۆدەکانی NCS Expert / E-Sys / BimmerCode |
| [docs/fault-codes](docs/fault-codes) | کۆدی هەڵەکان و چارەسەریان |
| [docs/guides](docs/guides) | ڕێنمایی هەنگاو بە هەنگاو |
| [tools](tools) | سکریپت و ئامرازەکان |

## ئاگاداری ⚠️
کۆدینگ دەتوانێت زیان بە ECU بگەیەنێت. هەمیشە **باکئەپ** بگرە و باتریەکە بە شارژەر بهێڵەوە.
هەرکەسێک ئەم زانیارییانە بەکاربهێنێت، بە بەرپرسیاریەتی خۆیەتی.
