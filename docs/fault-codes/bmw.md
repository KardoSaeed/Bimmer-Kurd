# کۆدی تایبەتی BMW (DME)

ئەم کۆدانە لە کۆمپیوتەری ماتۆڕ (DME) دان و بە hex نووسراون. واتاکانیان لە هەندێک مۆدێلدا جیاوازن، بۆیە هەمیشە دەقی کۆدەکە لە ئامێرەکەت بخوێنەوە.

## ئاگرنەگرتن

| کۆد | واتا | چی بپشکنیت |
|---|---|---|
| `29CC` | ئاگرنەگرتنی چەند سیلیندەرێک *(هێشتا پشتڕاست نەکراوەتەوە)* | شەمع، سووتەمەنی، دزەی هەوا |
| `29CD` | ئاگرنەگرتن – سیلیندەری ١ | کۆیڵ، شەمع، ئینجێکتەر |
| `29CE` | ئاگرنەگرتن – سیلیندەری ٢ | هەمان شت |
| `29CF` | ئاگرنەگرتن – سیلیندەری ٣ | هەمان شت |
| `29D0` | ئاگرنەگرتن – سیلیندەری ٤ | هەمان شت |
| `29D1` | ئاگرنەگرتن – سیلیندەری ٥ | هەمان شت |
| `29D2` | ئاگرنەگرتن – سیلیندەری ٦ | هەمان شت |

| کۆد | واتا | چی بپشکنیت | مەترسی |
|---|---|---|---|
| `29DC` | ئینجێکشن ڕاگیرا، پاڵەپەستۆ لە سیستەمی پاڵەپەستۆی بەرز کەمە | HPFP، LPFP، فلتەر، سێنسەرەکان | **بەرز** |
| `29F1` | پاڵەپەستۆی بەرزی سووتەمەنی، لۆژیکی نییە (plausibility) | HPFP، LPFP، سێنسەری ڕەیل | **بەرز** |
| `29F2` | پاڵەپەستۆی بەرزی سووتەمەنی زۆر کەمە | HPFP، LPFP، فلتەری گیراو | **بەرز** |
| `29F3` | کێشەی کارەبایی سێنسەری پاڵەپەستۆ (زۆرجار سێنسەری LPFP) | سێنسەر و وایەر | مامناوەند |
| `29E2` | سیگناڵی سێنسەری پاڵەپەستۆی ڕەیل | سێنسەر، HPFP، LPFP | مامناوەند |
| `29D9` | ئاگرنەگرتن بەهۆی سووتەمەنی کەمەوە | دابینکردنی سووتەمەنی | **بەرز** |
| `2FBE` | پاڵەپەستۆی سووتەمەنی دوای کوژاندنەوەی ماتۆڕ | زۆرجار یەک جار دێت. ئەگەر دووبارە بووەوە، HPFP و LPFP بپشکنە | نزم – مامناوەند |
| `2FBF` | پاڵەپەستۆی سووتەمەنی لە کاتی دەستپێکردن | HPFP | مامناوەند – بەرز |
| `2AAF` | لۆژیکی پەمپی سووتەمەنی | لە سەیارەی tune کراو باوە. ئەگەر لەگەڵ کۆدی تر هات، پەمپەکان بپشکنە | نزم |
| `30BE` | لۆژیکی کالیبرەیشنی ئینجێکتەر (IMA) | ئینجێکتەرەکان لە DME دا کۆد نەکراون | مامناوەند |

## پەمپی ئاو و BSD bus – N52 / N54 / N55 / N20

| کۆد | واتا | چی بپشکنیت | مەترسی |
|---|---|---|---|
| `2E81` | خێرایی پەمپی ئاوی ئەلیکترۆنی لە سنووری خۆی دەرچووە | پەمپی ئاو خەریکە تێکدەچێت. هەندێک سەرچاوە دەڵێن کێشەی پەیوەندییە | **بەرز** |
| `2E82` | پەمپی ئاو کوژایەوە، کارەبای زیاد (over-current) | پەمپی ئاو تێکچووە | **بەرز** |
| `2E83` | پەمپی ئاو لە دۆخی هێزی کەمدایە، یان بێ ئاو کار دەکات | پەمپ، هەوا لە سیستەمدا، کەمی ئاو | **بەرز** |
| `2E7C` | کێشەی پەیوەندی لە BSD bus | ئەو پارچانەی لەسەر bus ـەکەن: داینەمۆ، IBS، پەمپی ئاو، سێنسەری ئۆیڵ | مامناوەند |
| `2E9F` | کێشەی سێنسەری دۆخی ئۆیڵ (جار جار) | سێنسەر، BSD bus | نزم – مامناوەند |

!!! danger "پەمپی ئاو"
    ئەگەر کۆدی `2E81`، `2E82` یان `2E83` هات و گەرمی ماتۆڕ بەرز بووەوە، ڕابوەستە. گەرم بوونی زیاد دەتوانێت سەری ماتۆڕ (cylinder head) تێکبدات.
