# کۆدی هەڵەکان

کۆدی هەڵەکان دوو جۆرن:

- **[کۆدی OBD-II (P-codes)](obd2.md)**: ستانداردی جیهانین و لە هەموو سەیارەکاندا یەکن، بۆ نموونە `P0171`. هەر ئامێرێکی OBD ی هەرزان دەیانخوێنێتەوە.
- **[کۆدی تایبەتی BMW](bmw.md)**: بە hex دەنووسرێن، بۆ نموونە `2A87`. تەنها بە ISTA، INPA، یان ئەپی وەک BimmerLink و Carly دەخوێنرێنەوە.

!!! tip "پێش ئەوەی پارچە بگۆڕیت"
    1. کۆدەکە بنووسە، ئینجا بیسڕەوە (clear) و ببینە دەگەڕێتەوە یان نا.
    2. یەک کۆد بەتەنها هۆکاری کێشەکە نییە. هەمیشە سەیری هەموو کۆدەکان پێکەوە بکە.
    3. پێش گۆڕینی پارچەی گران، ئاسانترینەکان بپشکنە: کۆنێکتەر، وایەر، باتری.

!!! warning "ئاگاداری"
    ئەم زانیارییانە بۆ ڕێنماییە. هۆکارەکان بەپێی مۆدێل و ماتۆڕ جیاوازن. ئەگەر دڵنیا نیت، بیبە بۆ وەستا.
