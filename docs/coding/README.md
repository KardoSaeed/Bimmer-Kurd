# کۆدینگ

کۆدینگ واتە گۆڕینی ڕێکخستنەکانی ناو کۆمپیوتەرەکانی سەیارە (مۆدیولەکان) بۆ چالاککردن یان ناچالاککردنی تایبەتمەندییەکان.

| شاسی | ئامراز | کێبڵ |
|---|---|---|
| **E-series** (E90, E60, ...) | NCS Expert | K+DCAN |
| **F-series** (F30, F10, ...) | E-Sys | ENET |
| **G-series** (G20, G30, ...) | E-Sys (یان BimmerCode) | ENET |

!!! danger "پێش دەستپێکردن"
    1. باتریەکە بە **شارژەر** بهێڵەوە. ئەگەر ڤۆڵتی باتری لە کاتی کۆدینگدا دابەزێت، مۆدیولەکە تێکدەچێت.
    2. پێش هەر گۆڕانکارییەک **باکئەپی** ڕێکخستنی ئێستای مۆدیولەکە بگرە.
    3. ناوی پارامیتەرەکان بەپێی I-Step، LCI و ئامێرەکانی سەیارەکە دەگۆڕێن. هەمیشە لە CAFD/FA ی سەیارەکەی خۆت بیپشکنە.

**نیشانەکان:** ✔✔ واتە لە ٢ سەرچاوە یان زیاتر پشتڕاست کراوەتەوە. ⚠️ واتە ناوی پارامیتەرەکە هێشتا پشتڕاست نەکراوەتەوە، بۆیە ئێمە نایدەین تا دڵنیا دەبین. ✅ واتە ئەندامێکی کۆمیونیتی لەسەر سەیارەکەی خۆی تاقی کردۆتەوە.

!!! warning "تایبەتمەندییە مەترسیدارەکان"
    **ڤیدیۆ لە کاتی لێخوڕین** و **کوژاندنەوەی دەنگی قایش** مەترسییان بۆ گیان هەیە و لە زۆر وڵاتدا قەدەغەن. ئێمە ڕێنمایی کۆدینگیان بۆ نادەین.
    گۆڕانکاری لە گڵۆپەکاندا (fog، DRL، cornering) لە هەندێک وڵاتدا یاسای تایبەتی هەیە.

    ئامراز: **E-Sys**

    | داخستنی ئاوێنەکان بە قفڵکردن | FEM_BODY 3053 | `ASP_BEIKLAPPEN_BEI_KOMFORTSCHLIESSEN` | `aktiv` | ئاوێنەی قەدکراوەی پێویستە. ژمارەی بلۆکەکە لە CAFD ی خۆت بپشکنە |
